System Pillars & Capabilities

Headless Automation Engine

Built on Selenium 4 with modern Chrome headless support (--headless=new). Features anti-bot fingerprint masking, defensive explicit waits via WebDriverWait, dynamic DOM scrolling, and graceful timeout handling.

  • Thread-safe asynchronous background jobs
  • Real-time progress polling (800ms intervals)
  • Instant cancellation token support
Data Processing & Persistence

Uses high-performance Pandas DataFrames for data sanitization, type coercion (ratings to float, years to int), deduplication, and automated CSV synchronization under data/movies.csv.

  • Curated 250-movie offline demo fallback
  • Zero downtime on dataset reset or scrape
  • One-click RFC 4180 standard CSV export
Cinematic Intelligence UI

Engineered with a luxury dark cinematic aesthetic. Features interactive multi-column sorting, live instant search with debouncing, card vs table toggle, and 4 specialized Chart.js analytics charts.

  • Gaussian-style rating distribution histogram
  • Decade breakdown & timeline trend analysis
  • Deep-link modals with direct IMDb portal links
Architecture & Execution Pipeline
[Client Browser] ➔ HTTP Requests / Fetch API
↳ Flask Web Application (app.py)
├── Route Handlers: /dashboard, /movies, /analytics, /scraper, /about
├── Background Threading: threading.Thread(target=scraper.scrape_top_250)
├── Scraper Engine: Selenium Chrome WebDriver (Headless / Anti-detection flags)
│ ↳ Parses DOM: Title, Year, Rating, Rank, Poster Image, Movie URL
├── Storage Engine: Pandas DataFrames ➔ Synced to data/movies.csv
└── RESTful API Layer: JSON endpoints for live polling, filtering, & stats
↳ [UI Layer] Bootstrap 5 + Vanilla JS + Chart.js rendering interactive graphs & tables
RESTful API Specifications
JSON Responses
Method Endpoint Description Response Format
GET /api/stats Summary statistics (total movies, average rating, highest rated, last updated time). { "success": true, "stats": {...} }
GET /api/movies Query movies with support for q, min_rating, max_rating, year_from, year_to, sort_by, order, page, and per_page. { "movies": [...], "pagination": {...} }
GET /api/movies/<rank> Detailed attributes for a specific movie by rank (1 to 250). { "success": true, "movie": {...} }
GET /api/analytics Aggregated dataset metrics for charts (rating distribution, decade counts, top movies, scatter coordinates). { "rating_distribution": {...}, "decades": {...} }
POST /api/scrape Triggers non-blocking Selenium scraper thread. Accepts {"headless": true}. { "status": "started", "message": "..." }
GET /api/scrape/status Poll current scraper execution state, percentage progress, current title, and terminal logs. { "status": "running", "progress": 45, ... }
POST /api/scrape/stop Cancels any currently running scraper process and releases WebDriver memory. { "status": "cancelling", "message": "..." }
POST /api/clear Clears active scraped dataset or resets to curated demo dataset. { "status": "reset", "message": "..." }
GET /api/download Direct download of data/movies.csv as an attachment. Content-Type: text/csv
